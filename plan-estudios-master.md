# Comparativa de Opciones

## Semestre 1

| Aspecto | Opción A | Opción B |
|---------|----------|----------|
| Materias | Gestión avanzada de proyectos TIC + Fundamentos de ciberseguridad | Gestión avanzada de proyectos TIC + Visualización de datos |
| Enfoque | Gestión + Seguridad | Gestión + Datos |
| Complejidad | Baja + Baja | Baja + Baja |

## Semestre 5

| Aspecto | Opción A | Opción B |
|---------|----------|----------|
| Materias | Computación de altas prestaciones + Visualización de datos | Sistemas de gestión de la seguridad de la información + Fundamentos de ciberseguridad |
| Enfoque | Infraestructura + Datos | Seguridad completa |
| Complejidad | Alta + Baja | Media + Baja |

## Pros y Contras

### Opción A - Gestión + Ciberseguridad

| Pros | Contras |
|------|---------|
| Fundamentos de ciberseguridad antes de Sistemas de gestión de seguridad (secuencia lógica) | Visualización de datos queda al final, sin contexto de IA/Simulación reciente |
| Semestre 5 más exigente (Computación de altas prestaciones) | Temas de seguridad separados en el tiempo (semestre 1 y 5) |
| Base de seguridad desde el inicio | |

### Opción B - Gestión + Visualización de Datos

| Pros | Contras |
|------|---------|
| Visualización de datos temprana, útil para proyectos desde el inicio | Fundamentos de ciberseguridad tarde (semestre 5) |
| Semestre 5 enfocado 100% en seguridad (coherencia temática) | Pierdes la secuencia Fundamentos → Gestión de seguridad |
| Semestre 5 más ligero en complejidad | |

## Recomendación

**Opción A** es más recomendable si:
- Prefieres tener base de seguridad desde el inicio
- No te importa un semestre 5 más exigente

**Opción B** es más recomendable si:
- Quieres herramientas de visualización desde el principio
- Prefieres un semestre 5 más ligero antes del TFM
- Te gusta agrupar temas relacionados (seguridad completa en un semestre)
